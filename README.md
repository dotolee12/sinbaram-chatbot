# 신바람장날 카카오 가격·재고 챗봇

Google Sheets를 상품 장부로 사용하고, 카카오 챗봇 관리자센터의 스킬 요청에 답하는 Vercel 서버리스 프로젝트입니다. 가격·재고 질문은 규칙 기반으로 즉시 처리하고, 추천/요리 질문에만 Gemini를 선택적으로 호출합니다. Gemini 키가 없거나 무료 한도가 끝나도 기본 조회는 계속됩니다.

## 먼저 준비할 것

직접 로그인과 약관 동의가 필요한 아래 4가지는 사용자가 준비해야 합니다.

1. Google 스프레드시트 ID와 탭 `gid`
2. Google AI Studio의 Gemini API 키(선택 사항)
3. GitHub 및 Vercel 계정
4. 카카오톡 채널과 챗봇 관리자센터 봇

API 키를 채팅, GitHub, 시트에 적지 마세요. Vercel 환경 변수에만 입력합니다.

## 1. Google Sheets 만들기

`sample-products.csv`를 Google Sheets로 가져오거나 첫 행을 아래 순서로 만드세요.

`구분 | 품목 | 단위 | 가격 | 재고 | 특이사항 | 갱신시각`

- 재고는 `5마리`, `2박스`, `여유`, `품절`처럼 입력할 수 있습니다.
- 품절은 `품절`, `완판`, `소진`, `0`, `0개`를 인식합니다.
- 고객에게 보여주면 안 되는 원가, 거래처, 매출 정보는 이 공개 시트에 넣지 마세요.
- 우측 상단 **공유 → 일반 액세스 → 링크가 있는 모든 사용자(뷰어)**로 설정합니다.
- URL `https://docs.google.com/spreadsheets/d/시트ID/edit#gid=탭GID`에서 두 값을 복사합니다.

공개 링크 방식은 인증이 간단한 대신 링크를 아는 사람이 내용을 볼 수 있습니다. 고객 안내용 열만 둔 별도 시트를 권장합니다.

## 2. 로컬 확인

Node.js 20 이상에서 의존성 설치 없이 테스트할 수 있습니다.

```powershell
cd C:\market
npm test
```

## 3. GitHub와 Vercel에 배포

이 폴더를 새 GitHub 저장소에 올리고 Vercel에서 **Add New → Project → 저장소 Import**를 선택합니다. Framework Preset은 `Other`로 둡니다.

Vercel 프로젝트의 **Settings → Environment Variables**에 등록:

| 이름 | 값 | 필수 |
|---|---|---|
| `GOOGLE_SHEET_ID` | 시트 ID | 예 |
| `GOOGLE_SHEET_GID` | 탭 gid, 보통 `0` | 예 |
| `STORE_NAME` | 예: `신바람장날` | 아니오 |
| `GEMINI_API_KEY` | AI Studio 발급 키 | 아니오 |
| `GEMINI_MODEL` | `gemini-2.5-flash-lite` | 아니오 |

저장 후 다시 Deploy합니다. 배포 주소가 `https://예시.vercel.app`이면 스킬 URL은 `https://예시.vercel.app/api/chat`입니다. 브라우저에서 이 URL을 열어 `"ok": true`가 보이는지 확인하세요.

> 중요: Vercel Hobby는 공식 약관상 개인·비상업 용도입니다. 매장 영업용 운영은 무료 Hobby 조건에 맞지 않습니다. 시험은 가능하더라도 실제 상업 운영은 Vercel Pro 등 허용되는 요금제/호스팅 조건을 확인해야 하며, “영구 0원”은 보장할 수 없습니다.

## 4. 카카오 챗봇 연결

1. 카카오 챗봇 관리자센터에서 봇을 만들고 카카오톡 채널을 연결합니다.
2. **스킬 → 생성**에서 이름을 `시장가격안내`, URL을 `https://배포주소/api/chat`으로 저장합니다.
3. 스킬의 테스트 화면에서 아래 요청 예시로 전송합니다.

```json
{
  "userRequest": {
    "utterance": "샤인머스캣 얼마예요?"
  }
}
```

4. **시나리오 → 폴백 블록**에 스킬을 연결하고 응답을 **스킬 데이터 사용**으로 설정합니다.
5. 봇 테스트에서 가격, 품절, 추천 질문을 확인한 뒤 **배포**합니다.

카카오 스킬은 5초 안에 응답해야 합니다. 이 프로젝트는 시트/Gemini 호출을 각각 1.8초로 제한하며, Gemini 실패 시 기본 답변으로 돌아갑니다.

## 시험 질문

- `샤인머스캣 얼마예요?`
- `산낙지 있어요?`
- `지금 살 수 있는 과일 뭐 있어요?`
- `2만원으로 가성비 좋은 과일 추천해 줘`
- `복숭아 있어요?` (없는 상품을 지어내지 않는지 확인)

## 운영 주의

- 이 버전은 시트를 읽기만 하며 예약이나 자동 재고 차감은 하지 않습니다.
- 재고는 매장 판매 직후 직접 갱신해야 합니다.
- Gemini 무료 한도와 제공 모델은 Google 정책에 따라 바뀔 수 있습니다. 유료 결제를 켜지 않았다면 한도 소진 시 AI 추천만 기본 응답으로 대체됩니다.
- 배포 후 Vercel 로그와 카카오 **스킬 → 오류 내역**을 확인하세요.
